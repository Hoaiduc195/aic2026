# Runtime profiles

`dev` enables fixture-backed local work. `benchmark` records reproducible model
and index measurements. `aic2026-safe` is the rehearsal/final baseline: source
media is read-only, models must already exist locally, external network access
and organizer submission are disabled, and every future submission path must
require explicit human confirmation.

Organizer URLs, credentials, timestamp conversion, limits, and result-count
rules intentionally do not exist here until authoritative 2026 rules are
available.
